### 2. Folder Organization
- **inputs/**: All input data (models, configs, scripts)
- **tests/**: Test suite (11 classes, 62+ tests)
- **benchmarks/**: Performance benchmarks with system info
- **output/**: Generated images (organized by source)

### 3. Benchmark Accuracy Interpretation
**Critical Understanding:**
- "Profile Consistency" benchmark is NOT measuring absolute accuracy
- Comparison is against point-evaluation formula (biased toward astropy)
- Astropy: Point evaluation at pixel centers → perfect match (0.0000 deviation)
- Libprofit: Pixel integration → shows "deviation" but is MORE physically accurate
- The "deviation" is methodological difference, not error

### 4. Performance Characteristics
**Rendering Speed (256-1024 pixels):**
- Astropy: 11-29× faster than libprofit (no CLI overhead)
- Libprofit: ~0% PSF overhead (efficient convolution)
- Astropy: 500-22000% PSF overhead (FFT expensive)

**Recommendation:**
- Small images, no PSF: Use astropy
- Large images, PSF-heavy: Use libprofit
