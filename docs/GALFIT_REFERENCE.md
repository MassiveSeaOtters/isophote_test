# Reference for Using GALFIT: 

## From the Official Resource 

- GALFIT website: https://users.obs.carnegiescience.edu/peng/work/galfit/galfit.html 
- Instruction on using GALFIT (PDF File): https://users.obs.carnegiescience.edu/peng/work/galfit/README.pdf 
- Advisory for using GALFIT: https://users.obs.carnegiescience.edu/peng/work/galfit/advisory.html
- Top 10 Rule of Thumbs: https://users.obs.carnegiescience.edu/peng/work/galfit/TOP10.html
- Frequently Asked Questions: https://users.obs.carnegiescience.edu/peng/work/galfit/GFAQ.html

### Examples: 

- Batch automatic fit of simple models: https://users.obs.carnegiescience.edu/peng/work/galfit/distant.html
- Manual detailed fit of nearby galaxies: https://users.obs.carnegiescience.edu/peng/work/galfit/nearby.html 
- Fitting irregular galaxies with asymmetric features: https://users.obs.carnegiescience.edu/peng/work/galfit/newfeatures.html

### About the Configuration File 

- It is a structured ASCII file: 
    - The most basic usage example: https://users.obs.carnegiescience.edu/peng/work/galfit/example1 
    - An example config file that demonstrates all possible 2-D functions: https://users.obs.carnegiescience.edu/peng/work/galfit/example2
    - One that demonstrates the usage of the constraint file: https://users.obs.carnegiescience.edu/peng/work/galfit/EXAMPLE.CONSTRAINTS (note that this is not a complete GALFIT config file)
