## Immediate Next Task — mockgal `max_image_size` dataclass bug

### Symptom
Calling `mockgal.ImageConfig()` with default args raises:
```
AttributeError: 'ImageConfig' object has no attribute 'max_image_size'
```
The attribute is referenced by `ImageConfig.__post_init__` at
`mockgal.py:251` but never declared as a dataclass field. This breaks
`tests/test_mockgal.py::TestImageConfig::test_default_config` on both
`main` and `feature/galfit-parser` and blocked today's GALFIT integration
test from using `mockgal.generate_mock_image` to synthesize test images
(worked around in the integration test by calling `astropy.Sersic2D`
directly, but the underlying bug is still open).

### Related sites in `mockgal.py`
- `mockgal.py:82` defines `MAX_IMAGE_SIZE = 4001` as a module-level
  constant.
- `mockgal.py:251` (inside `ImageConfig.__post_init__`) reads
  `self.max_image_size` — the crash site.
- `mockgal.py:885` (inside `_compute_image_shape`) uses the module-level
  `MAX_IMAGE_SIZE` constant for the cap, not `self.config.max_image_size`.
- `mockgal.py:1381` (inside `load_image_configs`) passes
  `max_image_size=cfg_dict.get('max_image_size', MAX_IMAGE_SIZE)` into
  the `ImageConfig` constructor — this kwarg path is what the YAML
  manifests rely on (`inputs/huang2013/runs/*.yaml` all set
  `max_image_size: 4001`), so removing the kwarg is NOT an option.

### Fix direction
1. Add a new field to the `ImageConfig` dataclass:
   ```python
   max_image_size: int = MAX_IMAGE_SIZE
   ```
   Put it near the other size fields (`size_factor`, `size_pixels`)
   around `mockgal.py:194-195`.
2. Change `_compute_image_shape` at `mockgal.py:885` so the cap comes
   from `self.config.max_image_size` instead of the module-level
   `MAX_IMAGE_SIZE`. This is the behavior the Huang2013 manifests
   already assume.
3. Keep `MAX_IMAGE_SIZE = 4001` as the default value — many other tests
   and docs pin to it.
4. Confirm `tests/test_mockgal.py::TestImageConfig::test_default_config`
   passes. Run the full `tests/test_mockgal.py` suite to check for
   regressions.

### Branch
Create `bug-fix/imageconfig-max-image-size` **off `main`**, not off
`feature/galfit-parser`. The bug predates today's work and the fix
