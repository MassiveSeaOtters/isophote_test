## Key Decisions
- Decision: Huang2013 production runs are now defined by explicit YAML manifests, one row per mock configuration.
- Rationale: changing or extending the run set should be a data change rather than a Python edit.
- Decision: keep HSC `i`-band `wide` and `dud` values in a Huang2013 reference file and copy the numeric values inline into manifests rather than resolve profile names at runtime.
- Rationale: this keeps production runs fully explicit and reproducible.
- Decision: add `re_overall` to each Huang2013 galaxy and use it as the canonical image-size anchor.
- Rationale: the single largest component radius made the size predictions excessively large for this sample.
- Decision: use `size_factor = 6.0` as the current Huang2013 manifest default, but require it on each row.
- Rationale: some high-redshift or low-S/N rows may need a larger footprint than others.
- Decision: keep the baseline reference image low-noise rather than noise-free.
- Rationale: downstream algorithms behave unrealistically on perfectly noise-free images.
